# 开发路线图

更新日期：2026-10-26。

当前状态：M1 已验收；M2 内容获取进行中，每日新闻 `/v2/60s`、Bilibili 热搜 `/v2/bili`、知乎热榜 `/v2/zhihu`、抖音热搜 `/v2/douyin` 和今日头条热榜 `/v2/toutiao` 的异步获取、解析、内容快照、后台预览和有界缓存/手动刷新已完成；M2 仍未完成，内容组合尚未开始。

| 阶段 | 目标 | 验收条件 | 状态 |
|---|---|---|---|
| 设计准备 | 需求、配置、架构、Git 与许可 | 文档完整，目录精简 | 已完成 |
| M1 基础集成 | 固定宿主版本，建立真实插件、配置持久化和后台基础 | 实际加载/停用/重载，数据往返，版本源建立 | 已完成：通过基线宿主、后台 CRUD 和写操作结果确认验收 |
| M2 内容获取 | 五个核心接口、异步客户端、缓存、统一快照 | 夹具与真实站点低频验证，错误路径明确 | 进行中：五个 endpoint 和有界缓存/手动刷新已完成本地模拟/宿主/浏览器验证；内容组合和 M2 整体验收未完成 |
| M3 图文输出 | 文字/Markdown、图片模板与分页、后台预览 | 同快照一致，真实中文图片与长内容检查 | 未开始 |
| M4 白名单发送 | UMO 配置、手动查询、后台测试投递 | 空名单零发送，授权群聊/私聊实测 | 未开始 |
| M5 定时任务 | 计划、时区、记录、去重和恢复 | 固定时钟测试、重启不刷屏、重载无残留 | 未开始 |
| M6 首次发布 | 完善安装手册、迁移、平台矩阵和依赖 | MVP 需求验收，正式 v0.1.0 发布 | 未开始 |

每阶段分解为可验证的小改动，每个小改动独立提交。阶段不等于单个 commit，也不强制每阶段发布。

M1 验收基线为 AstrBot v4.29.1 / Python 3.12.13。41 项服务与 API 测试通过，真实 Dashboard 验证覆盖站点 CRUD、凭据处理、revision 冲突、停用/重载，以及请求或响应丢失后的重新读取确认。此验收不代表插件已可日常使用或兼容其他宿主版本。

## 实现前需要核验

已核验 AstrBot v4.29.1 的插件发现、加载、停用、启用与重载，插件数据目录、SQLite 站点存储、连接关闭，后台页面与 Web API 的鉴权/CRUD/停用后拒绝读写/重载替换，每日新闻、Bilibili 热搜、知乎热榜、抖音热搜、今日头条热榜的官方文档/源码，以及知乎、抖音、今日头条各一次成功公开实例响应。五种内容完整链路已用本地模拟上游完成宿主与浏览器验证；Bilibili 公开实例本次请求返回 HTTP 500，尚未用真实列表完成浏览器全链路。仍需核验：其他热榜接口、群成员隔离的出站会话语义、渲染器与中文字体、调度库 Cron/DST 行为。

开发与测试所需的真实 API 地址、平台账号和会话保持在本地配置，不写入公开仓库。

## 后续候选

扩展更多 endpoints、主题模板、历史内容查询。公开阅读页面、对外内容 API 或 AI 功能需另行明确范围，当前不提前建立代码目录和依赖。
