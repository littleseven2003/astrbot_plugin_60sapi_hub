# 变更记录

采用 SemVer 管理程序版本。当前开发版本为 `v0.1.0-dev.1`，尚无发布标签或正式可用版本。

## [Unreleased]

### 新增

- 新增手动投递核心：只读取已保存任务/组合/UMO，一次准备共享内容，复用现有预览和图片渲染；注入式发送器边界，逐目标逐页持久化发送前计划、成功、失败、unknown 和 skipped。
- SQLite schema v5 新增投递执行/目标/页记录；同执行标识幂等、并发去重、任务归属校验、配置 revision 复核、关闭/取消清理、重开遗留 pending 记 skipped、sending 记 unknown，不自动重试或补发。真实平台发送、后台发送入口、启用和调度仍未接入。

- 推送任务配置 CRUD 与后台管理：任务名称、已保存组合、纯文字/Markdown/图片输出、独立 UMO 白名单、revision 和时间；任务固定未启用，不发送、不调度、不请求上游。
- UMO 白名单按 AstrBot v4.29.1 的 `platform_id:message_type:session_id` 语义校验：支持群聊/私聊混合、空名单、去重保序和会话 ID 内冒号；拒绝裸 ID、非法类型、控制字符、超长和超量输入；群成员隔离会话原样保留。
- SQLite schema v3 增加 `push_tasks` 和 `push_task_umos`，从 v1/v2 事务迁移；任务 CRUD、revision 冲突、重启恢复、删除组合引用保护和并发引用约束；任务写响应丢失进入“结果未确认”，不按名称推断或自动重提。

- 站点配置模型与校验：HTTP(S)、内网、IPv6、反向代理前缀、误填 `/v2`、凭据、超时和 revision。
- 基于 SQLite 的站点管理服务，使用 `aiosqlite`，支持新增、列表、读取、编辑、删除、revision 冲突检测、凭据保留/替换/清除和写入回滚。
- AstrBot Dashboard 站点管理视图：列表、新增、编辑、启用/停用、超时、凭据保留/替换/清除和删除确认；包含加载、空列表、保存、校验失败、冲突和结果未确认状态。
- 受 Dashboard 鉴权的站点 Web API：列表、新增、读取、编辑、删除，服务端校验、revision 冲突、凭据脱敏、未登录拒绝和停用后拒绝读写；兼容宿主 bridge 的 GET/POST 调用方式。
- 站点管理 API 回归测试和真实浏览器验收：覆盖 CRUD、非法请求、未找到、冲突不覆盖、凭据语义、401/503、刷新/启用/重载、窄屏与控制台检查。
- 每日新闻 `/v2/60s` 获取：按站点 ID 读取内部配置，异步 HTTP、整体/连接/读取超时、2 MiB 响应上限、2 次尝试上限、拒绝重定向、并发上限和客户端生命周期管理。
- 每日新闻内容快照与解析：来源、接口、获取时间、内容日期、旧/缺失日期提示、有序条目和可选微语/链接；兼容字符串及 `{title,link}` 条目，合法空内容单独处理。
- 后台“内容预览”：选择已启用站点和内容类型主动获取，显示正常、空内容、旧内容、缺失日期、加载、失败和重试状态；打开页面、切换类型、保存站点和启动插件不自动请求；切换后不保留与当前选择不符的旧响应。
- 知乎热榜预览显示标题、可选摘要、原始热度文本和安全链接；不显示排名或更新时间，不自动加载封面图。
- 抖音热搜预览显示标题、原始整数热度值和安全搜索链接；不换算热度单位，不显示排名或更新时间，不自动加载封面图。
- 五类内容统一预览支持缓存命中/手动刷新；旧每日新闻独立 API 保持原有主动获取结构。
- 今日头条热榜预览显示标题、原始整数热度值和安全链接；不换算热度单位，不显示排名、摘要、标签或更新时间，不自动加载封面图。
- Bilibili 热搜 `/v2/bili` 解析与获取：按上游 `data` 数组保留标题/可选搜索链接、实际顺序和条数；合法空列表单独处理，不生成排名、热度或更新时间，畸形链接安全忽略。
- 知乎热榜 `/v2/zhihu` 解析与获取：按上游 `data` 数组保留标题、可选摘要、原始热度文本和可选安全链接、实际顺序与条数；合法空列表单独处理，不生成排名或更新时间，封面不渲染。
- 抖音热搜 `/v2/douyin` 解析与获取：按上游 `data` 数组保留标题、原始整数热度值和可选安全链接、实际顺序与条数；合法空列表单独处理，不换算热度单位，不生成排名或更新时间，封面不渲染。
- 今日头条热榜 `/v2/toutiao` 解析与获取：按上游 `data` 数组保留标题、原始整数热度值和可选安全链接、实际顺序与条数；合法空列表单独处理，不换算热度单位，不生成排名、摘要、标签或更新时间，封面不渲染。
- 统一内容预览增加有界进程内缓存：默认 TTL 300 秒、最多 32 项、LRU 淘汰；键包含站点 ID、内容类型、固定空参数和站点 revision；仅缓存成功快照（含合法空列表），错误不缓存。命中不请求上游，强制刷新绕过缓存但复用同键在途获取。
- 新增 `force_refresh` 严格布尔字段和独立 `cache` 元信息（`hit`、`expires_at`、`ttl_seconds`）；后台增加“刷新上游”，与“获取内容”共享忙状态。缓存命中不改变原 `fetched_at`、内容日期或上游指标；每日新闻跨中国日期失效并重新获取。
- 缓存读取前重新校验站点存在/启用；名称、地址、凭据修改通过 revision 隔离；停用/重载取消并等待缓存自有在途任务、清空后关闭客户端；同键等待者可独立取消，刷新失败不覆盖旧成功缓存。
- 内容组合持久化：稳定 ID、名称、站点、栏目数组顺序、revision 和时间；1～5 个现有类型，`limit` 为空或 1～1000，当前 `params` 只接受空对象。站点/组合共用同一 SQLite 连接和事务，schema v2 支持 v1 事务迁移、重启持久化和组合 CRUD revision 冲突。
- 内容组合后台 API 和页面：列表、新建、读取、编辑、删除、栏目多选/顺序/条数、组合预览与刷新；组合写操作沿用响应丢失后的读取确认。被组合引用的站点删除返回 409 并保留组合，不静默级联。
- 组合预览只请求选中内容，按配置顺序返回并逐栏截取，不修改完整内容缓存；复用 ContentService、缓存、共享 HTTP 并发预算和每日新闻日期语义。支持严格布尔 `force_refresh`；部分成功保留成功栏目和安全失败信息，全部失败返回 502 且不显示成空内容成功。
- 组合成功/部分成功响应增加同源 `outputs.text` 与 `outputs.markdown`：纯函数基于同一份组合版本、栏目顺序、截取条目、来源、获取时间、限制和日期提示生成，不修改领域快照/缓存，不再次请求上游。
- 组合页面增加纯文字/Markdown 源码切换、复制和 UTF-8 `.txt`/`.md` 下载；文件名使用固定前缀和组合 ID。格式切换、复制、下载不访问上游；全部失败/失效时清除输出并禁用操作。
- Markdown 输出对组合名、站点名、标题、摘要、热度和链接做 HTML/Markdown 转义和换行折叠，只对已有校验的 HTTP(S) 链接生成安全链接并编码括号/空格；不输出封面、HTML 或远程资源。剪贴板拒绝时选中文本并提示手动复制。
- 统一 `POST /<插件名>/content/preview`，只接受站点 ID 和固定的每日新闻/Bilibili 热搜/知乎热榜/抖音热搜/今日头条热榜类型；未知类型在请求上游前拒绝。保留每日新闻旧接口。
- 每日新闻、Bilibili 热搜、知乎热榜、抖音热搜与今日头条热榜共用一个异步 HTTP 客户端、连接池和全局并发预算，站点凭据按请求隔离。
- `httpx` 异步 HTTP 依赖，以及每日新闻/Bilibili/知乎/抖音/今日头条解析、共享客户端、统一 API 映射和本地模拟上游浏览器回归测试。
- 插件生命周期接入：初始化时打开站点数据库，停用或重载时关闭连接；数据位于宿主插件数据目录。

### 新增

- 推送任务配置 CRUD 与后台管理：任务名称、已保存组合、纯文字/Markdown/图片输出、独立 UMO 白名单、revision 和时间；任务固定未启用，不发送、不调度、不请求上游。
- UMO 白名单按 AstrBot v4.29.1 的 `platform_id:message_type:session_id` 语义校验：支持群聊/私聊混合、空名单、去重保序和会话 ID 内冒号；拒绝裸 ID、非法类型、控制字符、超长和超量输入；群成员隔离会话原样保留。
- SQLite schema v3 增加 `push_tasks` 和 `push_task_umos`，从 v1/v2 事务迁移；任务 CRUD、revision 冲突、重启恢复、删除组合引用保护和并发引用约束；任务写响应丢失进入“结果未确认”，不按名称推断或自动重提。

- 支持组合预览显式生成固定样式中文分页图片：预览响应增加短期 `image_snapshot`，图片接口只接受不透明快照 ID，不重新请求上游。图片最多 6 页、900×1200、总字节受限，后台逐页展示和下载 PNG；部分失败可见，全部失败不生成。
- 图片快照有 TTL、数量、总大小和单快照大小限制，校验用户归属及组合/站点 revision；配置变更、删除、停用和过期要求重新预览，插件关闭清理快照和线程池。
- 图片使用 Pillow 和宿主 CJK 字体，在线程池中渲染并设置并发/超时；失败不影响文字/Markdown。页面不加载远程字体、封面、CDN 或公共渲染服务。

### 修复

- 投递服务从准入开始跟踪自有任务，关闭后不再启动新执行；并发 close 等待同一清理，不取消无关任务。
- 发送前在最后一条记录写入后、外部调用前重新核对生命周期和配置；最终校验之后不再写入，避免使用过期检查发送。
- 总截止时间覆盖准入、排队、准备和发送；并发和等待数量有界，满额明确拒绝。
- 区分未开始的 skipped 与可能进入外部调用的 unknown，保留已知成功/失败；关闭、取消、超时、重启恢复采用同一规则。
- 同一执行标识的并发创建冲突校验任务归属，其他任务不能拿到记录。
- 发送器状态严格规范化，错误码仅保存受控内部值，不持久化平台回显或凭据。

- 修复 UMO 校验对内部字段二次 trim 的问题：现在只去整条输入首尾空白，平台字段空白明确拒绝；session ID 前导/内部空白、大小写和内部冒号原样保存，去重基于完整规范化值。
- 修复推送任务修改/删除的非法 `expected_revision` 被映射成 500 的问题：缺失、null、布尔、零、负数、小数、字符串现在返回 400 `validation_error` 和字段 `expected_revision`，不写入；过期整数仍返回 409。

- 图片渲染准入名额覆盖后台线程实际生命周期：超时/取消后未结束线程继续占用名额；排队上限 4、执行上限 2，20 秒总超时覆盖排队和执行，排队/关闭请求有明确错误。超长标题、数字和 URL 使用二分分块换行，避免只生成一行或反复测量超长字符串。
- 字体发现和显式字体路径增加中文字形覆盖验证；可加载但不含中文的字体不会被采用，缺少合格字体时返回 `font_unavailable`。
- 修复图片准入名额在内部清理等待期间取消时泄漏的问题：只有清理完成并无 await 返回时才正式移交名额，首次/再次取消和关闭交错均归还一次，不因取消降低后续可用容量。

- 修复组合复制异步回调归属：复制开始时捕获格式、文本、输出 epoch 和操作序号；格式切换、预览刷新/失效、组合切换、编辑或更新复制后，旧成功/拒绝回调不能修改提示、焦点、选区或按钮；并发复制只保留最新操作，拒绝权限时仍选中文本并提示手动复制。
- 修复组合列表刷新、编辑或删除后旧预览仍显示的问题：清理当前组合失效结果，预览响应校验请求令牌、组合 ID、配置签名和 revision，旧响应不能覆盖新配置；旧请求不再清除新请求 busy，失效不自动获取上游。
- 修复最后一个缓存等待者退出后，共享获取任务清理期间仍可能被同键新请求加入并收到 CancelledError 的竞态：取消时立即移除在途记录并标记，新请求发起新获取；旧任务仍由缓存任务集合管理，关闭时等待清理，且不能覆盖新缓存或删除新记录。
- 修复站点新增、编辑、删除被取消后事务残留，避免下一次写入提交被取消的操作。
- 拒绝站点地址中的 CR、LF、Tab、NUL 等控制字符，避免解析器静默删除字符后保存不可用地址。
- 修复站点列表加载完成后仍残留“正在读取站点…”状态的问题。
- 修复新增、编辑或删除请求的响应丢失后直接恢复写按钮、可能重复提交的问题：结果未确认时禁止重提，要求先重新读取最新列表；读取失败保持未确认，读取成功后由管理员确认实际状态。
- 修复每日新闻上游 HTTP/业务错误正文可能回显 Bearer 凭据的问题：后台只返回程序生成的安全提示和数字状态码/business code，不返回或记录上游错误正文。
- 修复每日新闻客户端关闭时在途、排队或重试等待请求可能继续使用已关闭连接的问题：关闭先拒绝新请求，再取消并等待本客户端自有任务，最后关闭连接；外部取消继续传播，关闭幂等，重新打开不受旧请求影响。
- 修复内容预览事件绑定和每日新闻空状态文案，避免页面初始化失败。
- 修复窄屏下内容类型下拉框继承纵向 flex 尺寸而异常增高的问题。
- 修复未知内容类型提示只列出部分已支持类型的问题：提示改为由当前支持列表动态生成。
- 修复可选链接触发 `urlsplit` 异常时导致整次每日新闻/Bilibili 热搜预览失败的问题：未闭合 IPv6 方括号和 NFKC 非法的 Unicode 主机按无链接处理，合法 HTTP(S)/IPv6 保留；必要标题缺失仍报结构错误。
