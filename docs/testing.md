# 测试与验收手册

当前仅有最小插件入口，无业务代码或业务测试。已完成的宿主加载/停用/重载检查见开发手册的“AstrBot 兼容性基线”；其余阶段只检查链接、格式、Git hooks 行为和内容一致性，不用空测试宣称插件可用。

## 测试层级

- 单元：纯配置验证、JSON 解析、时间计算；合成或脱敏夹具，默认不联网。
- 服务：mock HTTP、临时数据库、假时钟和假发送器。
- 宿主：指定版本 AstrBot 中加载、页面、配置、渲染、停用及重载。
- 平台：明确授权的测试群聊/私聊，验证文字、图片和主动投递。

mock 测试通过不等于真实投递成功。检查报告区分通过、失败、未执行和环境阻塞。

## 验收矩阵

| 范围 | 必测场景 |
|---|---|
| URL | 尾斜杠、反代前缀、误填 /v2、凭据与跨源跳转 |
| HTTP | 超时、429、500、业务错误、非 JSON、响应过大、有限重试 |
| 解析 | 正常、合法空榜、缺必要字段、类型变化、不伪造数据 |
| 组合 | 排序、条数、参数校验、同快照文字/图片一致 |
| 渲染 | 中文字体、长标题、超长列表、多栏目、分页无遗漏/重复 |
| 白名单 | 群聊/私聊混合、空列表、重复 UMO、裸 ID、未知实例、复杂会话 ID、成员隔离 |
| 操作 | 预览/保存零发送；测试仅发名单内目标；移除目标后不继续投递 |
| 调度 | 每日/每周/间隔/Cron、时区/DST、下次执行、重启与重载 |
| 投递 | 部分目标/页成功、超时 unknown、成功项不重发、崩溃恢复 |
| 数据日期 | 旧早报、迟到更新、缺日期、重试截止 |
| 后台 | 鉴权、服务端校验、凭据脱敏、并发编辑冲突、引用删除 |
| 存储 | 迁移与回滚、重启持久化、缓存隔离、在途文件清理 |

## 视觉检查

实际生成图片，检查中文缺字、手机宽度可读性、超长标题、来源日期、分页和空内容；保存脱敏样图可用于使用文档。

后台必须在真实宿主中验证添加、修改、保存、重启恢复和错误状态，不能以静态效果图代替功能验证。

## 平台支持

目前没有经过本项目实测的平台。在首个可用版本文档中逐项记录适配器和版本、群聊/私聊、文字/图片、主动推送能力及限制，不笼统声明全平台支持。

## 发布验证

核对 metadata 版本与标签/变更记录；运行必要检查；确认包内无凭据和运行数据；验证干净安装与旧数据迁移。不得通过删除失败测试或弱化断言掩盖问题。
