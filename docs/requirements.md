# 需求说明

状态：MVP 未完成。M1、M2、M3 已通过基线验收；M4 任务配置、独立 UMO 白名单、投递核心、aiocqhttp 适配层、后台手动投递/执行记录及聊天帮助/列表/纯文字/图片查询已实现，聊天图片查询已通过 PR #19 隔离验收。真实账号投递未验证。M5 每日计划配置、持久化和下次时间预览已实现，实际启用、调度执行和恢复尚未实现。本文定义首个 MVP 的产品范围，详细证据见[测试手册](testing.md)。

## 目标

用户在 AstrBot 后台添加 60s API 站点，选择一个或多个内容接口；插件获取 JSON 后生成可读文字、Markdown 和图片，通过机器人向指定群聊或私聊定时推送。

管理后台由 AstrBot 管理员使用，接收者无需访问后台或额外注册账号。

## 首批内容

每日新闻、B站热搜、知乎话题榜、抖音热搜、今日头条热搜。微博、百度、小红书、IT 资讯和 AI 资讯后续按适配情况扩展。B站热搜不等于热门视频榜。

一个内容组合引用一个站点；一个推送任务引用一个内容组合，可向多个 UMO 发送。暂不做跨站点内容混合或自动切站。

## 主要行为

- 新任务默认停用；启用前校验组合、白名单和时间。
- 预览、保存配置、首次安装均不自动发送消息。
- 删除被引用的站点或组合时提示引用关系并阻止操作。
- 部分接口失败可按设置发送可用栏目，但需记录缺失；全部失败不发送空日报。
- 每栏独立限制条数，不补造条目，不改变上游排名。
- 推送支持度以实际平台验证为准，不承诺所有适配器都能主动发消息。

## 范围之外

独立 Docker 网站、公共阅读站、外部公共 API、AI 摘要、跨平台语义聚类、任意未知 endpoint 自动排版、自动向全局白名单广播、必需的绑定指令。

## 首次发布条件

R01–R12 有实现和验收结果；目标 AstrBot 加载/重载/停用通过；至少一个授权测试平台验证群聊、私聊、图片及定时投递；许可证、作者、依赖和安装手册齐备。
