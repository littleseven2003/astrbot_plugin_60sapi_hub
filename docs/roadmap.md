每阶段分解为可验证的小改动，每个小改动独立提交。阶段不等于单个 commit，也不强制每阶段发布。

M1 验收基线为 AstrBot v4.29.1 / Python 3.12.13。41 项服务与 API 测试通过，真实 Dashboard 验证覆盖站点 CRUD、凭据处理、revision 冲突、停用/重载，以及请求或响应丢失后的重新读取确认。此验收不代表插件已可日常使用或兼容其他宿主版本。

M2 验收日期为 2026-10-26，代码基线为 `00aa992`。范围为五个接口、共享 HTTP 与缓存、站点/组合持久化及后台预览；迁移回滚、取消清理、引用保护、部分失败和旧响应失效已验证。完整范围与未验证项见 [测试与验收](testing.md#m2-验收基线)。M2 验收当时不包含图文输出；M3 已于 2026-10-27 单独完成基线验收，见下文。

M3 验收日期为 2026-10-27，最终代码提交 `7b48ee6`，PR #10 合并提交 `78da616`，版本仍为 `v0.1.0-dev.1`。范围为同一次内容组合预览的文字、Markdown、固定样式分页图片，后台格式切换/复制降级/文字导出/图片预览与逐页下载，图片快照归属与 revision 校验，中文字体覆盖检查，以及渲染超时、取消、关闭清理和前端旧响应保护。Python 3.12.13、3.13.13 各 227 项测试通过；验收范围和边界见[测试手册](testing.md#m3-验收基线)。此验收不代表完整版本兼容、真实消息平台或公开上游持续可用。M3 验收当时未覆盖后续 M4；当前 M4 后台手动投递范围见下文。

2026-10-29 验收，最终代码 `e115b29`，PR #15 合并提交 `68a01cb`，版本保持 `v0.1.0-dev.1`。Python 3.12 / AstrBot v4.29.1 源码环境 301 项测试通过，真实 Dashboard bridge 浏览器回归连续三次通过；发送使用假机器人或请求拦截。范围包含配置确认、稳定执行标识、未确认结果查询、历史只读/分页、跨任务隔离和弹窗生命周期保护，见[测试手册](testing.md#m4-后台手动投递验收基线)。

## 实现前需要核验

已核验 AstrBot v4.29.1 的插件发现、加载、停用、启用与重载，插件数据目录、SQLite 站点存储、连接关闭，后台页面与 Web API 的鉴权/CRUD/停用后拒绝读写/重载替换，每日新闻、Bilibili 热搜、知乎热榜、抖音热搜、今日头条热榜的官方文档/源码，以及知乎、抖音、今日头条各一次成功公开实例响应。五种内容完整链路已用本地模拟上游完成宿主与浏览器验证；Bilibili 公开实例本次请求返回 HTTP 500，尚未用真实列表完成浏览器全链路。仍需核验：其他热榜接口、真实账号下的群聊/私聊及群成员隔离投递、调度库 Cron/DST 行为；图片渲染器和中文字体已在 M3 基线中验证，但其他平台字体环境仍未验证。

开发与测试所需的真实 API 地址、平台账号和会话保持在本地配置，不写入公开仓库。
