# 测试与验收手册

当前已有最小插件入口、站点存储、后台站点管理页/API、每日新闻、Bilibili 热搜、知乎热榜、抖音热搜和今日头条热榜获取、统一预览缓存与手动刷新和对应测试；其他热榜、组合、渲染、发送和调度尚未实现。站点服务测试使用临时 SQLite；宿主验证覆盖加载/停用/启用/重载、未登录拒绝、停用后拒绝读写、CRUD、凭据脱敏、revision 冲突、真实浏览器页面操作和本地模拟上游的五种内容链路。

## 当前检查

- 服务级：在仓库根目录安装 `requirements.txt` 后运行 `python -m unittest discover -s tests -v`，覆盖合法/非法站点地址、控制字符、名称/超时/凭据边界、CRUD 与重开持久化、revision 冲突、凭据保留/替换/清除、写入回滚和 schema 版本。
- 接口回归：`tests/test_site_api.py` 覆盖站点列表、新增、读取、编辑、删除，非法请求体、字段校验、未找到、revision 冲突且不覆盖、删除冲突、凭据保留/替换/清除与脱敏、存储不可用和未预期错误的通用响应。接口业务测试不替代真实宿主鉴权和页面验收。
- 取消回归：用独立 SQLite 连接持有写锁，等待写操作已排队后取消任务，再释放锁；覆盖新增、编辑、删除取消后的下一次正常写入和重开数据库，确认未提交修改不落盘。不要用固定 sleep 判断写操作已进入等待。

### 每日新闻本地模拟回归

使用本地 HTTP 上游提供 `/proxy/v2/60s`、`/proxy/v2/bili`、`/proxy/v2/zhihu`、`/proxy/v2/douyin` 和 `/proxy/v2/toutiao`，通过控制端点切换正常、空内容、旧日期、缺失日期、HTML、HTTP 500、非 JSON、重定向、超大响应和慢响应。站点配置为内网回环地址和反向代理前缀，带虚构 Bearer 凭据；检查请求路径保留前缀、Authorization 正确、响应不泄漏凭据。Bilibili 模拟列表只包含标题/链接；知乎模拟列表包含标题/摘要/热度文本/可选链接；抖音/今日头条模拟列表包含标题/原始整数热度/可选链接，不附加排名或更新时间，封面地址不渲染。

浏览器应等待 `#preview-result`、`#preview-empty`、错误状态或列表数量等实际 DOM 状态，不能以固定 sleep 代替。五种内容类型分别截图；打开页面、切换类型、保存站点和启动插件前后比较模拟上游请求计数，确认没有自动请求。切换类型后旧结果必须清空，响应必须与当前选择一致。编辑器或站点写操作失败不应改变预览状态，反之预览失败也不得触发站点保存/删除。重定向模式需确认模拟目标没有收到第二次请求和 Authorization。

### 页面发现的本地注意

AstrBot v4.29.1 会解析插件根目录并要求其位于 `data/plugins` 下。用符号链接把仓库挂到 `data/plugins` 时，视图不会出现在插件页；这是宿主路径边界。页面验收应把仓库复制为实际插件目录（开发手册的 smoke 命令使用 `tar` 复制），或使用正式安装目录。

### 写操作响应丢失回归

AstrBot 4.29.1 的视图 bridge 只把失败转换为带一条 `message` 的 `Error`，不保留 HTTP 状态、错误码或响应体。页面只能把已知的服务端拒绝消息（字段校验、未找到、revision 冲突、鉴权/停用、存储不可用）视为明确失败，其余错误按结果未确认处理；不要伪造 bridge 不存在的状态字段。

复现方法：在 Playwright 等浏览器自动化中拦截目标写请求，可用 `route.fetch()` 先让请求真正到达宿主取得响应，再 `route.abort('failed')` 丢弃客户端响应；模拟请求未到服务器时直接中止连接。断言页面进入未确认面板、写按钮禁用、不能关闭后直接重提；重新读取失败时状态不变；重新读取成功后显示最新列表状态。新增记录检查使用服务器列表数量和实际内容，不用同名/同地址推断归属；编辑检查 revision 只增加一次；删除检查目标是否仍在列表，不盲目重发。

操作应等待 DOM 状态、列表数量或 API 结果变化，不能用固定 sleep 代替状态判断。截图、日志和临时脚本保存在仓库外。

## 测试层级

- 单元：纯配置验证、JSON 解析、时间计算；合成或脱敏夹具，默认不联网。
- 服务：mock HTTP、临时数据库、假时钟和假发送器。
- 宿主：指定版本 AstrBot 中加载、页面、配置、渲染、停用及重载。
- 平台：明确授权的测试群聊/私聊，验证文字、图片和主动投递。

mock 测试通过不等于真实投递成功。检查报告区分通过、失败、未执行和环境阻塞。
