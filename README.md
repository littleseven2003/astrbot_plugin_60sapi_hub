# 60sAPI Hub

基于 [60s API](https://github.com/vikiboss/60s) 的 AstrBot 资讯聚合与订阅插件，计划支持多站点配置、多接口组合、文字与图片生成，以及群聊和私聊白名单定时推送。

**M1、M2、M3 已完成基线验收；M4 的推送任务、UMO 白名单、投递核心、aiocqhttp 适配层和后台手动测试/执行记录已实现并完成隔离验收。管理员可显式向任务白名单测试投递文字、Markdown 源码或分页图片；聊天提供帮助、当前会话可见任务列表、按任务 ID 的纯文字内容查询和中文分页图片查询。真实账号发送尚未验证；每日计划配置和理论下次时间预览已完成隔离验收（361 项测试、零跳过），任务启用和实际调度尚未实现，MVP 未完成，尚无发布版本。**

## 已实现

- 可被 AstrBot 发现、加载、停用、启用和重载的最小插件入口。
- 站点配置模型：名称、基础地址、启用状态、超时、可选 Bearer 凭据和 revision。
- HTTP(S)/内网/IPv6/反向代理前缀地址校验，以及误填 `/v2`、用户信息、查询串和 fragment 的明确拒绝。
- SQLite 站点增删改查、revision 冲突检测，以及凭据的保留、替换和清除。
- 插件停用/重载时关闭数据库连接，初始化失败时释放已创建资源。
- 嵌入 AstrBot Dashboard 的中文站点管理视图：列表、新增、编辑、启用/停用、超时和凭据维护、删除确认；加载、空列表、保存、校验失败、冲突和结果未确认状态；响应丢失时要求重新读取后再决定。
- 受 Dashboard 鉴权的插件 Web API：列表、新增、读取、编辑、删除；服务端校验、revision 冲突、凭据保留/替换/清除；停用后旧处理器拒绝读写，重载后不重复注册可写处理器。
- 站点管理页不会回显凭据原文，不使用 CDN、外部字体或独立 HTTP 服务，也不自行保存 Dashboard token。
- 每日新闻 `/v2/60s` 获取：按站点 ID 由服务端读取地址、启用状态、超时和凭据；异步 HTTP、响应大小限制、有限重试、超时、拒绝跨源重定向、关闭时等待自有请求，以及错误正文不回显凭据的客户端生命周期管理。
- 每日新闻内容快照：来源、接口、获取时间、上游内容日期、旧内容/缺失日期提示和有序新闻条目；合法空内容与结构错误分开处理。
- 后台“内容预览”：选择已启用站点和内容类型后主动获取；每日新闻显示内容日期和旧内容提示，Bilibili 热搜显示标题/链接，知乎热榜显示标题、摘要、热度文本和链接。普通获取优先使用未过期缓存，“刷新上游”强制请求；打开页面、切换类型、保存站点和启动插件不会自动请求上游。
- Bilibili 热搜 `/v2/bili`：返回 `data` 数组，只使用上游明确的标题和可选搜索链接；保留实际顺序和条数，不把列表序号当排名，不生成热度或更新时间。
- 知乎热榜 `/v2/zhihu`：返回 `data` 数组，使用标题、可选摘要、原始热度文本和可选安全链接；保留实际顺序和条数，不把列表序号当排名，不生成排名或更新时间，不自动请求封面图片。
- 抖音热搜 `/v2/douyin`：返回 `data` 数组，使用标题、原始整数热度值和可选安全搜索链接；保留实际顺序和条数，不换算热度单位，不把列表序号当排名，不生成或解释更新时间，不渲染封面。
- 今日头条热榜 `/v2/toutiao`：返回 `data` 数组，使用标题、原始整数热度值和可选安全链接；保留实际顺序和条数，不换算热度单位，不把列表序号当排名，不生成或解释更新时间，不渲染封面。
- 五种 endpoint 共用一个异步 HTTP 客户端和全局并发预算；每日新闻的日期语义与 Bilibili/知乎/抖音/今日头条的列表语义分别保留。
- 统一内容预览使用进程内有界缓存：默认 TTL 300 秒、最多 32 项、LRU 淘汰；普通获取命中缓存时不请求上游，页面另提供“刷新上游”强制刷新。缓存键包含站点、内容类型、固定空参数和站点 revision，不包含凭据。
- 内容组合使用同一 SQLite 持久化：一个组合引用一个站点，按数组顺序选择 1～5 个现有内容类型，每栏条数为空或 1～1000；组合预览只请求选中的 endpoint，按配置顺序返回并逐栏截取，单内容缓存保持完整。被组合引用的站点不能删除。
- 组合成功或部分成功预览同时生成纯文字和 Markdown 源码，两者共享同一组合版本、栏目结果、顺序、截取条目、来源和时间；切换格式、复制或下载不会重新请求上游。Markdown 对不可信文本和链接做转义，不渲染 HTML、封面或远程资源。
- 组合预览可在后台显式生成固定样式中文图片：服务端短期保存同一份已验证预览快照，按排版分页，不重新请求 60s API、不读取后来更新的缓存。页面展示每页 PNG 并可逐页下载；部分失败用红色说明，全部失败不生成图片。
- 推送任务配置使用同一 SQLite 存储：任务名称、已保存组合、输出方式（纯文字/Markdown/图片）和独立 UMO 白名单；支持 CRUD、revision 冲突、组合引用保护和重启恢复。任务仍保持未启用；可选每日计划可在任务页面配置，只保存配置并显示理论下次时间，不启动调度器；保存不发送、不请求上游，后台测试投递是单独的显式操作。
- 投递核心按已保存任务读取组合、输出格式和 UMO，准备一次共享内容，按目标/页写入执行记录并调用注入的发送器；明确成功、明确失败和 unknown 分离，异常/超时/取消保守记为 unknown，不自动重试、不重启补发。入口已装配 aiocqhttp 发送适配层并注册 Dashboard 鉴权的手动投递接口；装配、启动和查询本身不发送消息。
- 新增 AstrBot v4.29.1 aiocqhttp/OneBot v11 发送适配层：按 UMO 平台实例 ID 精确查找真实实例，通过 Context/MessageSession/MessageChain 路由到对应平台实例；验收时将最终机器人网络边界替换为假机器人；其他适配器、未知实例、非法会话/载荷在调用前拒绝。Markdown 作为纯文本源码发送，图片使用内存 PNG bytes；适配层已接入后台手动投递，真实账号网络发送尚未验证。
- 聊天发现命令 `/60s`、`/60s help`、`/60s list [页码]` 和 `/60s get <任务ID>`：list 只读取并展示当前 UMO 精确匹配、组合存在且来源站点启用的任务元信息；get 在精确授权后复用组合缓存预览，只回复一条有界纯文字内容；不显示其他会话任务、UMO、站点地址或凭据，不主动广播、不写配置、不渲染图片。
- 聊天图片命令 `/60s image <任务ID>`：精确授权后复用组合缓存和单次内容快照，以每次查询独立归属生成中文分页 PNG，按页序构造一条内存图片回复；回复前复核白名单和配置 revision，停用或重载后的旧查询不回复。图片失败提供文字查询提示，不广播、不写配置。
- UMO 使用 `平台适配器实例ID:GroupMessage|FriendMessage:完整会话ID`，只按前两个冒号分隔并保留会话 ID 内冒号；支持群聊/私聊混合、空名单、去重保序，拒绝裸 ID、非法类型、控制字符和越界长度。后台明确提示使用 /sid 获取完整 UMO。
- 图片使用 Pillow 在受限线程池中渲染，最多 2 个执行、4 个排队，20 秒总超时覆盖排队和执行；页面 900×1200、最多 6 页、总像素 8,000,000、总 PNG 12 MiB；单个文本字段超过 200,000 字符或排版行数超过 360 行会提前拒绝；快照 TTL 300 秒、最多 32 个、总大小 8 MiB。图片接口沿用 Dashboard 鉴权并校验快照归属和组合/站点 revision。

最小插件入口、站点存储、后台站点管理和内容预览已建立。站点配置可通过 AstrBot Dashboard 的“站点管理”页面或受鉴权的插件 Web API 新增、读取、编辑、启用/停用和删除，并持久化到插件数据目录的 SQLite。每日新闻、Bilibili 热搜、知乎热榜、抖音热搜和今日头条热榜预览按站点 ID 和内容类型获取上游 JSON，并解析为各自的内容快照；统一预览优先使用未过期缓存，可手动刷新。内容组合可持久化站点、栏目顺序和每栏条数，并按组合配置进行部分失败容忍的组合预览；成功结果同时提供纯文字、Markdown 源码和显式生成的分页图片，可在后台查看、复制和逐页下载。后台显式测试可调用已接入的 aiocqhttp 发送路径并查询逐目标逐页结果；其他热榜、任务启用和实际调度尚未实现，真实账号发送未验证。

已在 AstrBot v4.29.1 / Python 3.12.13 的隔离源码环境验证加载、停用、启用和重载，以及真实 Dashboard 登录后的站点管理与内容预览页/API：数据库位于 `data/plugin_data/astrbot_plugin_60sapi_hub/sites.sqlite3`，停用后连接关闭，启用/重载保留数据且无重复实例；未登录请求被拒绝，停用后的旧处理器返回不可用，凭据不会回显。每日新闻、Bilibili 热搜、知乎热榜、抖音热搜和今日头条热榜完整链路使用本地模拟上游验证正常、空内容、HTML 文本、HTTP/业务/非 JSON/超时/大小限制/重定向、停用/重载和窄屏场景；统一预览另验证首次获取、缓存命中、强制刷新、配置 revision、禁用/删除、刷新失败保留旧缓存和在途关闭；内容组合另验证 SQLite v1→v2 迁移、CRUD/revision、引用站点删除拒绝、部分/全部失败、逐栏截断和重启持久化；组合文字输出验证双格式同源、Markdown 转义/链接安全、复制、UTF-8 下载、全部失败清空和配置失效；组合图片另验证快照 TTL/淘汰/归属、配置变更/删除/停用失效、同一快照不重新请求上游、多页分页（本轮验收复核 3 页 900×1200 PNG）、逐页下载、部分失败和全部失败；知乎公开实例返回 30 条、抖音/今日头条公开实例各返回 50 条真实列表，Bilibili 公开实例本次请求返回 HTTP 500，未把演示站点配置为默认站点。真实消息平台、其他热榜和真实公开实例浏览器全链路未验证。验证方法与兼容范围见[开发手册](docs/development.md#astrbot-兼容性基线)。
