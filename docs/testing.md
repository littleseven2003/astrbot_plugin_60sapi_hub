# 测试与验收手册

当前已有最小插件入口、站点存储、后台站点管理页/API、五类内容获取、统一预览缓存与手动刷新、内容组合持久化/预览、纯文字/Markdown、分页图片、推送任务配置/UMO 白名单及假发送器投递核心；其他热榜、真实平台发送、后台发送入口和调度尚未实现。站点服务测试使用临时 SQLite；宿主验证覆盖加载/停用/启用/重载、未登录拒绝、停用后拒绝读写、CRUD、凭据脱敏、revision 冲突、v1→v2 迁移、组合引用删除拒绝、真实浏览器页面操作和本地模拟上游的五种内容及组合链路。

## M2 验收基线

2026-10-26 验收通过，代码基线 `00aa992`，插件版本仍为 `v0.1.0-dev.1`，不是正式发布。宿主基线为 AstrBot v4.29.1、Python 3.12.13；浏览器为 Chromium。

- 自动化：`python -m unittest discover -s tests -q` 共 195 项通过；`node --check views/sites/app.js` 和 Git diff 检查通过。最终合并未改变已验证的程序、测试及页面文件。

公开实例证据沿用 [参考资料](references.md) 中注明日期的低频核验：每日新闻、知乎、抖音、今日头条曾取得成功响应；Bilibili 当次返回 HTTP 500，适配结构通过官方源码/文档及模拟上游验证。本次里程碑复核没有重复请求公开实例，不能据此保证其当前或持续可用。

未验证范围：公开实例浏览器全链路、其他兼容实例/部署版本、其他 AstrBot/Python/操作系统/浏览器、多进程与崩溃恢复，以及真实消息平台、图片输出的其他平台字体环境和白名单投递/调度。M2 通过表示内容获取与后台预览基线可进入 M3，不表示首个 MVP 已完成。

- 后台：真实 AstrBot v4.29.1 Dashboard 登录后验证任务保存、刷新、编辑、删除、重载持久化、引用保护、写响应丢失后的锁定/重新读取/人工确认、390px 窄屏；未登录任务接口 401，插件停用后 503。

## M4 投递核心验证

本轮只验证假发送器投递核心，不验证真实平台发送，也不新增后台发送按钮或公开投递 Web API。

- 输入仅限已保存任务 ID 和执行标识；组合、输出格式、UMO 和内容均从任务/预览读取，不接受调用方任意 UMO、URL、正文或文件路径。
- 假发送器记录实际调用次数、UMO、页号和载荷；验证群聊/私聊混合、空名单零内容零投递、多目标共享一次内容、图片页顺序、文字/Markdown 单逻辑消息。
- 状态验证：明确成功、明确失败、unknown、超时、取消、部分成功；失败/unknown 后停止当前目标剩余页，其他目标继续；只有明确成功计成功。
- 幂等：同执行标识重复、并发、完成后再调用均不重复发送；成功后写库失败保守 unknown，不自动重试；重启/重开把未开始的 pending 记录归 skipped、已进入发送的 sending 记录归 unknown，保留已知成功/失败，不补发。
- 配置变化：执行期间删除任务、移除目标、修改组合/任务、停用站点后停止尚未开始投递；不加入新目标。
- 资源：默认最多 20 目标、6 页、2 并发执行、4 个等待执行、单次执行总截止 60 秒、发送器调用 15 秒；关闭取消自有执行并等待，不取消无关任务；并发 close 等待同一清理。
- schema v3/v4→v5 迁移成功/失败回滚，保留旧站点、组合、任务数据；旧数据库重开恢复遗留执行状态。
- 真实宿主：AstrBot v4.29.1 启动后宿主库升至 v5，既有站点/组合/任务读取正常；插件启动未装配发送器，未发送消息、未新增投递 Web API。既有预览路由存在性用缺失组合 404 守卫验证，未触发上游。

边界：真实平台适配器、真实群聊/私聊投递、后台发送入口、任务启用、调度和重启恢复发送未实现/未验证。投递核心通过不代表真实平台可用。

- 缓存 API：首次 `cache.hit=false` 并请求上游；再次 `cache.hit=true` 且请求计数不变、`fetched_at` 不变；`force_refresh=true` 请求上游且 `cache.hit=false`；`cache.expires_at` 为 UTC ISO 8601，`cache.ttl_seconds=300`。站点改名/改地址/换凭据后 revision 变化，下次获取重新请求；停用/删除在读取缓存前拒绝且不增加请求。
- 内容组合模型/存储：字段、1～5 项、重复类型、顺序、`limit=null/1/1000` 和拒绝布尔/零/负数/小数/字符串/1001、空参数/非空参数；CRUD/revision、重开持久化、v1→v2 迁移保留站点/凭据/revision、并发站点删除与组合创建无悬空引用。
- 组合引用：被引用站点删除返回 409 `site_referenced` 和组合名称；组合删除后可删除站点；不级联删除组合。
- 组合预览：只请求选中类型、按配置顺序、逐栏截取且完整单内容缓存不受影响；普通命中/刷新；站点 revision 隔离；部分成功保留成功栏目并列出安全失败；全部失败 502/`status=failed`，合法空列表仍成功；禁用站点在请求前 409；错误正文和凭据不外泄。
- 组合浏览器：创建/调整顺序/设置条数/保存/编辑/刷新页面/重启后持久化；请求计数只增加选中栏目；缓存命中、刷新；单内容预览完整；部分/全部失败状态；revision 冲突；引用站点删除拒绝；写响应丢失后重新读取确认；停用/重载；窄屏与安全文本。
- 组合输出单元：`tests/test_profile_render.py` 验证两格式同源且不修改输入；文字顺序/限制/日期提示/空栏目/零值热度/失败栏目；Markdown 对标题、换行、HTML、围栏、括号链接的转义与安全降级。
- 组合输出 API：成功/部分成功响应包含 `outputs.text` 和 `outputs.markdown`，与已截取栏目一致；全部失败无 outputs；输出不含凭据或原始上游正文。
- 组合输出浏览器：格式切换、复制、UTF-8 下载不增加上游请求；下载文件名固定前缀+组合 ID；剪贴板成功提示与拒绝时选中文本/手动复制提示；HTML 文本、部分失败输出、全部失败清空输出和配置失效均验证。
- 图片单元：`tests/test_profile_image.py` 真实渲染 PNG，覆盖中文长标题/长摘要/单条跨页、多分区、空列表、热度 0、未知/旧日期、部分失败、页数/字节/字体/取消限制；同快照渲染字节确定性。
- 图片快照：`tests/test_image_snapshots.py` 覆盖 TTL、数量/LRU、总字节、单快照大小和关闭清理；`tests/test_profile_image_api.py` 覆盖归属、过期、组合修改/删除、站点停用、全部失败无快照、同快照不重新请求上游和图片超限保留文字。
- 图片服务：`tests/test_image_service.py` 覆盖排队/准入上限、总超时、线程不响应取消、取消后新请求、关闭期间排队请求、准入清理期间首次/再次取消、多轮取消容量稳定、关闭与取消交错、线程池释放和后台任务有界。
- 图片浏览器：真实宿主 + 本地模拟上游，验证显式生成、请求计数不增加、分页展示、逐页 PNG 下载/文件名/有效文件、格式切换保留图片、部分失败、全部失败清空、配置失效、旧图片响应/旧 finally 不覆盖或解锁新请求、图片失败后文字/Markdown 可用、窄屏无溢出。真实 macOS 宿主用 Hiragino Sans GB 生成多页长图并逐页查看（本轮验收复核 3 页）；另验证组合名 80 个连续 W 的标题换行和超长链接拆分，以及 Arial 等无中文覆盖字体被拒绝。Linux 字体缺失环境未实机验证，预期应显示 `font_unavailable` 而不是伪造图片。
- 复制归属浏览器：用可控 Promise 暂停纯文字复制后切换 Markdown，旧回调不能误报 Markdown；暂停复制后失效/刷新并完成或拒绝旧复制，旧回调不能修改提示、焦点、选区或按钮；两次复制反序完成只保留最新提示；拒绝权限时选中文本并提示手动复制。
- 剪贴板真实验证边界：隔离 AstrBot v4.29.1 iframe 实际拒绝自动剪贴板，验证的是降级路径；成功回调通过可控 Promise 模拟，不能写成真实系统剪贴板写入成功。
- 组合预览失效：暂扣旧预览响应，改名/改顺序/条数并刷新列表后释放，旧名称和栏目不显示；旧请求不清理新请求 busy；已有预览后编辑、删除当前组合但保留其他组合、普通列表刷新分别验证清除/保留，并确认无自动上游请求。
- 客户端关闭：真实宿主在慢速强制刷新在途时停用或重载，确认预览返回已分类的 503/安全错误，不出现 RuntimeError；停用后上游请求计数不再增加，重新启用/重载后缓存为空、五种内容均能重新获取。

### 每日新闻本地模拟回归

使用本地 HTTP 上游提供 `/proxy/v2/60s`、`/proxy/v2/bili`、`/proxy/v2/zhihu`、`/proxy/v2/douyin` 和 `/proxy/v2/toutiao`，通过控制端点切换正常、空内容、旧日期、缺失日期、HTML、HTTP 500、非 JSON、重定向、超大响应和慢响应。站点配置为内网回环地址和反向代理前缀，带虚构 Bearer 凭据；检查请求路径保留前缀、Authorization 正确、响应不泄漏凭据。Bilibili 模拟列表只包含标题/链接；知乎模拟列表包含标题/摘要/热度文本/可选链接；抖音/今日头条模拟列表包含标题/原始整数热度/可选链接，不附加排名或更新时间，封面地址不渲染。

浏览器应等待 `#preview-result`、`#preview-empty`、错误状态或列表数量等实际 DOM 状态，不能以固定 sleep 代替。五种内容类型分别截图；打开页面、切换类型、保存站点和启动插件前后比较模拟上游请求计数，确认没有自动请求。切换类型后旧结果必须清空，响应必须与当前选择一致。编辑器或站点写操作失败不应改变预览状态，反之预览失败也不得触发站点保存/删除。重定向模式需确认模拟目标没有收到第二次请求和 Authorization。

### 页面发现的本地注意

AstrBot v4.29.1 会解析插件根目录并要求其位于 `data/plugins` 下。用符号链接把仓库挂到 `data/plugins` 时，视图不会出现在插件页；这是宿主路径边界。页面验收应把仓库复制为实际插件目录（开发手册的 smoke 命令使用 `tar` 复制），或使用正式安装目录。

### 写操作响应丢失回归

AstrBot 4.29.1 的视图 bridge 只把失败转换为带一条 `message` 的 `Error`，不保留 HTTP 状态、错误码或响应体。页面只能把已知的服务端拒绝消息（字段校验、未找到、revision 冲突、鉴权/停用、存储不可用）视为明确失败，其余错误按结果未确认处理；不要伪造 bridge 不存在的状态字段。

复现方法：在 Playwright 等浏览器自动化中拦截目标写请求，可用 `route.fetch()` 先让请求真正到达宿主取得响应，再 `route.abort('failed')` 丢弃客户端响应；模拟请求未到服务器时直接中止连接。断言页面进入未确认面板、写按钮禁用、不能关闭后直接重提；重新读取失败时状态不变；重新读取成功后显示最新列表状态。新增记录检查使用服务器列表数量和实际内容，不用同名/同地址推断归属；编辑检查 revision 只增加一次；删除检查目标是否仍在列表，不盲目重发。

操作应等待 DOM 状态、列表数量或 API 结果变化，不能用固定 sleep 代替状态判断。截图、日志和临时脚本保存在仓库外。
