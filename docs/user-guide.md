# 使用手册

**当前没有可安装版本。** 站点管理、每日新闻、Bilibili 热搜、知乎热榜、抖音热搜和今日头条热榜预览已在开发源码和隔离宿主中验证，但尚未发布；组合文字/Markdown 和分页图片已可预览，其他热榜、发送或聊天命令仍未实现。首次可用版本发布后会补充安装方式和兼容矩阵。

## 运行条件

需要兼容的 AstrBot、可访问的 60s API 站点、已连接的消息平台；图片模式还需要宿主环境安装 Pillow 并具备可用的中文字体。最低宿主版本及平台支持以实际发布说明为准。

## 当前可用范围（开发源码）

在隔离的 AstrBot v4.29.1 中，登录 Dashboard 后可打开插件视图“站点管理”：

- 查看已保存站点，新增、编辑或删除站点。
- 修改名称、基础地址、启用状态和超时；地址支持内网、Docker 主机名、方括号 IPv6 和反向代理路径前缀，不应以 `/v2` 结尾。
- 编辑凭据时默认保留原值，也可设置新值或清除；保存后只显示“已设置/未设置”，不会回显原文。
- 站点保存只做服务端格式校验，不会请求 60s API；内容预览是单独的主动操作。字段校验失败会保留已填写的表单，修正后可再次提交；revision 冲突会重新读取列表，不自动覆盖他人修改。
- 如果保存或删除过程中网络中断、超时或响应丢失，页面会进入“结果未确认”状态：服务器可能已经完成，也可能没有收到请求。此时保存/删除按钮和关闭操作会被锁住，不能直接重复提交；请先点击“重新读取最新列表”。重新读取失败时会继续保持未确认。重新读取成功后，页面会显示最新列表状态；系统不会仅凭名称或地址判断新增记录是否来自本次提交，请人工检查列表后再决定是否关闭并重新打开表单。

### 内容预览

在“内容预览”区域选择一个已启用站点和内容类型，点击“获取内容”。打开页面、切换类型、保存站点和启动插件都不会自动请求上游；只有点击按钮才会获取选中的 endpoint。

**每日新闻**

- 显示来源站点、接口 `/v2/60s`、上游内容日期、获取时间和按上游顺序排列的新闻条目；条数按实际返回，不固定为 15 条。
- 上游返回 `news: []` 时显示“合法空内容”，这不是错误。
- 内容日期缺失或无法识别时显示“未知”；内容日期早于当前中国日期时会提示旧内容，但保留原日期，不会用抓取时间冒充今天。

**Bilibili 热搜**

- 显示来源站点、接口 `/v2/bili`、获取时间、实际条数和按上游顺序排列的标题/可选链接。
- 上游返回 `data: []` 时显示合法空列表，这不是错误。
- 当前接口没有排名、热度或更新时间；页面不显示这些指标，也不把列表序号当排名。获取时间是本插件的请求时间，不是上游更新时间。
- 链接缺失或格式不安全时只忽略链接；标题中的 HTML 只作为文本显示，不执行。

**知乎热榜**

- 显示来源站点、接口 `/v2/zhihu`、获取时间、实际条数和按上游顺序排列的标题、可选摘要、原始热度文本和可选链接。
- 上游返回 `data: []` 时显示合法空列表，这不是错误。
- 热度文本（例如“1670 万热度”）原样显示，不换算成数值；当前接口没有排名或更新时间，页面不显示这些指标，也不把列表序号当排名。
- 封面图片地址不渲染，不会自动请求远程图片；标题、摘要、热度中的 HTML 只作为文本显示。
- 链接缺失或格式不安全时只忽略链接，不影响标题、摘要和热度。

五种内容切换后旧结果会清空，不会把其他内容类型的结果显示成当前类型。网络、HTTP、业务结构、缓存等待超时或响应过大失败会显示错误，按钮恢复后可主动重试；失败不会保存、删除站点或发送消息。

**缓存与刷新**

- “获取内容”优先使用 300 秒内成功获取的快照，命中时不会请求上游；“刷新上游”跳过已完成缓存，强制重新获取。
- 缓存最多 32 项，按最近使用淘汰；只缓存成功结果，合法空列表也会缓存，错误不会缓存。
- 结果中的“缓存”显示“缓存命中”或“本次上游获取”，“缓存有效至”显示本地时间的过期时刻；原“获取时间”和内容日期不会因缓存命中改变。
- 刷新失败会明确报错，不会把旧数据说成刷新成功；如果上一份缓存仍未过期，之后点“获取内容”仍可看到它。
- 站点改名、改地址或修改凭据后，旧缓存不会复用；站点停用或删除后不会继续返回缓存。
- 每日新闻跨中国日期后不会继续使用昨日缓存，重新获取并重新计算旧内容提示。
- 预览缓存只在当前进程内有效；插件停用、重载或 AstrBot 重启后清空。旧每日新闻独立 API 保持原有响应，不受本页缓存按钮影响。

**内容组合**

- 在“内容组合”区域新建组合：填写名称、选择一个已保存站点，勾选 1～5 个现有内容类型，使用“上移/下移”调整顺序，并在每栏填写最多展示条数。留空表示展示全部，正整数范围为 1～1000。
- 当前五类接口没有可配置参数，页面不展示参数编辑器；组合只引用已保存站点和现有类型，不能填写任意 URL。
- 可以引用已停用站点保存组合，但预览会明确提示站点未启用，不发起上游请求。
- “组合预览”只请求组合选中的栏目，按配置顺序显示，并按每栏条数截取；单内容预览仍显示完整列表。普通获取使用缓存，“刷新组合”跳过已完成缓存。
- 结果分为“完整成功”“部分成功”“全部失败”。部分失败会保留成功的栏目并列出失败栏目和安全错误；全部失败不会显示成空内容成功。合法空列表算成功。
- 组合编辑/删除使用 revision 冲突保护；被组合引用的站点不能删除，页面会提示引用关系。写操作响应丢失时先重新读取组合列表确认，不直接重复提交。
- 组合列表刷新后，如果当前组合的名称、revision、站点或栏目配置发生变化，或当前组合被删除，页面会清除当前组合预览，不会把旧 revision 的结果继续显示。编辑/删除当前组合也会立即失效旧预览。
- 暂扣的旧预览响应即使稍后返回也不能覆盖新配置；旧请求不会清除新请求的忙状态。失效只清除页面结果，不会自动重新请求上游。
- 组合保存在插件数据目录的 SQLite 中，重启后保留；组合内容快照不持久化。
- 成功或部分成功的组合预览下方提供“纯文字”和“Markdown 源码”切换、复制和下载。两种格式来自同一次预览结果，切换格式、复制或下载不会重新请求上游。
- 下载文件为 UTF-8 的 `60sapi-profile-<组合 ID>.txt` 或 `.md`，不会直接使用组合名称拼接文件名。
- 复制会锁定本次操作的格式、文本和输出身份；完成后如果格式、预览、组合或输出已经变化，不会修改新的提示、焦点或选区。多次复制并发时只让最新操作更新提示。
- 复制只有浏览器实际写入剪贴板成功后才提示成功；如果宿主 iframe 或浏览器拒绝剪贴板权限，页面会选中当前文本并提示手动复制。当前隔离 AstrBot v4.29.1 iframe 复核的是权限拒绝后的降级路径；成功回调分支使用可控 Promise 验证，不代表真实系统剪贴板写入成功。
- 全部失败、组合切换、编辑、删除或列表使预览失效时，旧输出会清除，复制和下载按钮禁用；不会把旧文本当作本次结果。
- 成功或部分成功预览提供“生成图片”按钮。图片是显式操作，打开页面、保存配置、切换文字/Markdown 或复制不会自动生成。
- 图片使用同一次预览的短期快照，不会重新请求 60s API，也不会读取后来更新的缓存；服务端按排版分页，页面显示每页图片并可逐页下载 PNG。
- 图片包含组合名、来源、成功/部分成功状态、预览生成时间、栏目获取时间、真实时间/日期提示、标题、摘要、热度和页码；部分失败栏目以红色说明。全部失败不生成图片。
- 图片固定页面为 900×1200，最多 6 页；超过页数、总像素、单页/总字节或渲染时间会明确提示失败，文字和 Markdown 保持可用。图片生成和下载不消耗上游请求次数。
- 组合或站点被修改、删除、停用，快照过期，或当前用户与快照归属不一致时，图片生成会要求重新预览，不会静默替换内容或重新获取。快照默认有效 300 秒。
- 图片下载文件名为 `60sapi-profile-<组合 ID>-page-<页码>.png`，不会使用组合名称或服务器路径。图片样式固定，暂不支持主题编辑、封面、远程字体或远程图片。

白名单、发送和调度尚未实现。不要把这个页面当作可用的日报插件。

## 使用流程

1. 安装正式发布的插件，在 AstrBot 后台打开插件管理页面。
2. 添加 API 站点；当前开发版会校验名称、地址、超时和凭据格式，不提供连通性测试按钮。
3. 新建内容组合，选择站点、勾选已有内容类型、调整顺序和条数。
4. 生成文字或图片预览。预览不发送消息。
5. 新建任务，填写群聊/私聊 UMO 白名单、时间与时区。
6. 显式向选定白名单会话测试发送，确认内容后启用任务。
7. 查看下次执行时间及运行记录。

组合图文预览已可用；发送、定时步骤和聊天查询仍为设计名称，发布前会按实际界面更新，不提供虚构的可用命令。

## 获取白名单标识

使用 AstrBot 内置 /sid 获取当前会话 UMO，具体见 [配置说明](configuration.md)。插件不要求额外绑定操作。空白名单不发送。

如果改过指令前缀，应使用对应前缀。群聊隔离场景须确认群级推送标识，不能只凭纯群号猜测平台。

## 常见问题

**保存时网络中断，能直接再点一次保存吗？**

不能。网络异常不能证明服务器没有保存；直接重试可能新增重复站点或重复修改。页面会要求先重新读取最新列表。重新读取成功前不要刷新或重复提交；确认列表状态后，再按页面提示关闭并重新操作。

**为什么没有“测试连接”按钮？**

当前没有单独的连通性测试按钮。站点保存只做格式校验；“获取内容”优先使用未过期缓存，“刷新上游”会实际请求所选 endpoint（每日新闻 `/v2/60s`、Bilibili 热搜 `/v2/bili`、知乎热榜 `/v2/zhihu`、抖音热搜 `/v2/douyin` 或今日头条热榜 `/v2/toutiao`），可用于验证该站点的基础地址、网络和凭据。其他 endpoint 尚未适配，不能据此推断全部接口可用。

**接口站点在浏览器能打开，插件却连不上？**

请求从 AstrBot 所在设备/容器发出，需要检查该环境的网络。容器里的 localhost 通常指容器本身，不能直接当作其他服务地址。

**Markdown 为什么在聊天中不是网页样式？**

不同平台对 Markdown 的支持不同。后台可以提供标准预览；聊天会使用平台支持的格式或文字/图片。

**为什么旧新闻没发？**

任务会根据内容日期判断是否为今日；旧内容按策略跳过或等待更新。

**后台显示生成成功，但消息没到？**

获取、渲染和投递是不同步骤。检查具体目标的发送记录、平台权限和连接状态。主动推送窗口和媒体限制取决于平台。

**重启后会补发所有漏掉的日报吗？**

默认只恢复未来计划，避免集中补发。投递状态未知的消息不默认自动重试。
